Reference run of tools/bias_attribution.py against the real market data.
=======================================================================

Recorded so that the figures quoted in README.md and docs/bias-audit.md
remain checkable from inside the repository, even though the market data
itself is private and the notebook carries no stored outputs.

Anyone holding the CSVs can regenerate this and diff against it:

    python tools/bias_attribution.py \
        --nq Data/nq-10y-1min.csv \
        --qqq Data/QQQ_daily.csv

A byte-identical result confirms the engine still reproduces both
published result sets. A difference means either the data file or the
engine has changed, and the reproduction check at the bottom will say
which endpoints broke.

Notes on reading this
-----------------------------------------------------------------------

The benchmark control block is the strongest single piece of evidence in
the audit. QQQ's price series is identical between the two runs, so the
move from Sharpe 0.6375 to 0.7683 cannot come from the benchmark. It comes
entirely from sampling the equity curve on trading days rather than
padding it to calendar days while still annualising with 252. The observed
ratio 1.2052 against the closed form sqrt(365/252) = 1.2036 matches to
0.13%.

The step table is cumulative: each row's delta is marginal given every
correction above it, not that bias measured in isolation against the
untouched legacy baseline. The engine is path-dependent, since position
size follows the running account value.
